# QA Department

## Role
ตรวจภาพอย่างอิสระกับ brief และเกณฑ์รับงาน; ไม่แก้ไฟล์ภาพด้วยตัวเอง

## Queue
`Context/quests/qa/`

## Checklist
1. องค์ประกอบครบตาม brief ไม่มีตัวหนังสือ/โลโก้ที่ไม่ได้ขอ
2. Anatomy, pose, มือ/นิ้ว, เท้า, มุมหัน และการจับว่าวดูสมเหตุผล
3. Land Rover Series ใช้ reference ที่ตรงประเภท; silhouette/ชิ้นส่วนรถไม่ผิดชัด
4. หมาไทยหลังอานอ่านออกและอยู่ในท่าที่ระบุ
5. เป็น graphic design รูปทรงชัด ไม่เป็น animation; จำกัดหมึก 2–3 สี ไม่รวมพื้นขาว
6. PNG เปิดได้และไม่มีงานอื่นที่ไม่ได้สั่ง

## Sub Agent
| Agent | Model | หน้าที่ |
|---|---|---|
| graphic-qa | gpt-6.1-terra | ตรวจด้วยภาพและส่ง PASS หรือรายการแก้ที่ชี้ตำแหน่ง/เกณฑ์ |

## Handoff
บันทึกผลใน `Context/qa/`; PASS ส่ง PM เพื่อส่งผู้ใช้ตรวจ, FAIL ส่งรายการแก้ให้ Designer ผ่าน PM
